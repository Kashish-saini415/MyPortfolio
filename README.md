# Kashish Saini - Developer Portfolio

Single-page portfolio for an **AI/ML Engineer, GenAI Engineer, Full Stack Developer and Software Engineer**.
Built with plain HTML, Tailwind CSS (CDN), Typed.js and a little vanilla JavaScript. No build step needed.

**Live:** https://kashish-saini415.github.io/MyPortfolio/

## Sections
Home, Highlights, About, Skills (by role), Experience, Projects, Contact.

## Run locally
```bash
git clone https://github.com/Kashish-saini415/MyPortfolio.git
cd MyPortfolio
python -m http.server 5500
```
Then open http://localhost:5500 (internet is needed for the Tailwind, Typed.js and FontAwesome CDNs).
You can also use the VS Code **Live Server** extension and click "Go Live".

## Files
- `index.html` - page structure and content
- `style.css` - custom styles and animations
- `script.js` - navbar highlighting, typing effect, scroll reveal, contact form
- `assets/` - images (`image1.png`, `image2.jpeg`, `image3.jpeg`, `image44.jpg`) and `my-cv.pdf`
